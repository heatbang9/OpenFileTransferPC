# OpenFileTransfer PC 디자인

![OpenFileTransfer PC icon](../assets/brand/openfiletransfer-icon-512.png)

## 콘셉트

PC 앱은 연한 민트색 바탕, 태극형 양방향 흐름, 위/아래 화살표 로고를 중심으로 디자인합니다. 서버와 클라이언트를 동시에 수행하는 PC 앱 특성에 맞게 상태, 탐색, 전송, 수신함 영역을 한 화면에서 스캔할 수 있게 구성했습니다.

## 색상

| Token | Hex | 용도 |
| --- | --- | --- |
| Mint 50 | `#E9FFF6` | 화면 배경, 선택 상태 |
| Mint 300 | `#BFEFD9` | 패널/버튼 테두리 |
| Mint 600 | `#2BBF8A` | 브랜드 포인트 |
| Teal 700 | `#147D67` | 주요 버튼 |
| Teal 900 | `#0A5C4D` | 버튼 아이콘, 로고 선 |
| Ink | `#15372F` | 주요 텍스트 |

## UI 규칙

- 버튼과 패널 radius는 8px을 기본으로 둡니다.
- 주요 액션은 `Teal 700` 배경을 사용합니다.
- 보조 액션은 흰색 배경과 민트 테두리를 사용합니다.
- 버튼에는 서버, 탐색, 파일, 전송, 수신함 의미가 보이는 아이콘을 함께 씁니다.
- 모바일 앱과 동일한 로고 자산과 색상 토큰을 유지합니다.
